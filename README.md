# Account Plan Setup

Living Agentic Account Plan Setup prototype (Technician / Admin).

## Local preview

```bash
cd prototype
npm install
python3 -m http.server 8765 --bind 127.0.0.1
```

Open [http://127.0.0.1:8765/landing/index.html](http://127.0.0.1:8765/landing/index.html).

## Versions

- **Version 3 (live):** `prototype/` root create flow
- **Version 0 / 1:** frozen under `prototype/versions/`

## GitHub Pages

The site is published from `main` via GitHub Actions. After deploy, open the Pages URL from the repository **Settings → Pages**.
