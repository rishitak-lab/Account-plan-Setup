# Account Plan Setup

Living Agentic Account Plan Setup prototype (Technician / Admin).

## View online

GitHub Pages publishes this repository. Open the landing page from the repository’s Pages URL (`/prototype/landing/index.html`), or use the root redirect.

## Local preview

```bash
cd prototype
python3 -m http.server 8765 --bind 127.0.0.1
```

Open [http://127.0.0.1:8765/landing/index.html](http://127.0.0.1:8765/landing/index.html).

SLDS assets are vendored under `prototype/node_modules/@salesforce-ux/design-system/assets` for static hosting.
